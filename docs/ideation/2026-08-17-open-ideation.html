Grounding Context

Atoms turns yesterday’s daily notes into a second brain. It files them as atoms (your words stay as you wrote them), shows a few back on Home, and lets you Ask questions of the vault. Capture stays outside the plugin. People pay with Plus or bring their own key.

Rules we do not break: never rewrite the capture body, never invent folders, never file today on its own, never turn Home into a to-do list, never copy atom bodies back from the cloud.

The last two weeks went to Plus sign-in and Settings. The older gap is still this: after a week of real notes, does the vault feel like a brain, or a pile of files? The first live vault run filed everything correctly and still failed — the links said “preference about Nichita” instead of a real why, and some keepable ideas were thrown away as noise. Ask can also lie: if your words and the question do not share the same words, it looks like the vault is empty. Home has one quiet look for “nothing to show,” “something is blocked,” and “filing is broken.”

1 After Process, speak one real connection

Confidence 78% Complexity Medium
Description
Right now, after Process, Home lists the new titles and then goes quiet. Treat that moment as the proof. Show one real “why these two notes belong together,” in your words — or say, honestly, “filed, but not linked.” Also say what got thrown away in that run (noise, weak reasons, rescued ideas). A week of real captures counts as done only when the vault can speak one sentence a friend would recognize as yours. A vault full of empty “about X” links is not the same as a rest day.
Basis
direct: The first live vault run wrote the files correctly and still failed: links were empty labels, and some real ideas were marked as tasks or noise. After Process, Home lists titles and freezes the stream. A second brain that only files never helps you remember.
external: A pretty graph nobody can speak from is a museum, not a brain.
reasoned: The tests we run prove “a file was written.” The product fails a different way. The one moment you are looking is right after Process. Spend it on a connection, not a receipt.
Rationale
This changes what “it worked” means. Good reasons stop being a cleanup job and become the thing we ship.
Downsides
Easy to turn into a score or a guilt badge. The “what we threw away” line can look like an error log. Keep it to one sentence, rare, never a streak.

Sketch: same moment after Process, spent on a connection instead of a list.

2 Write the “why” once, and make it quote the other note

Confidence 82% Complexity High
Description
Every atom already stores links with a reason. Write that reason as a small structured object: what kind of link it is, why, and whether the model or a later cleanup wrote it. A reason only counts if it quotes a phrase from the other note’s body. Cleanup code then accepts or rejects — it stops rewriting empty phrases. Home and Ask only use strong reasons. The row you scan can be the why; opening it puts you between the two original notes.
Basis
direct: The model is already asked for “revises / contradicts / relates.” Prompt examples taught empty reasons, and cleanup then pasted the same empty phrases back in. Home’s “connected” card only means “these two notes share a link chip.” Plugin and Plus must keep the same classify shape.
external: Bees follow a lively dance, not a limp one that still points somewhere.
reasoned: If Home, Ask, and “also about” each re-read a weak sentence, fixing one reason helps one note. One shared object means the next quality pass helps all four.
Rationale
The product’s intelligence is supposed to live in the links. This makes a link something we can check, and stops Home from showing you the bug as if it were a memory.
Downsides
Has to change classify in the plugin and on Plus together. Requiring a quote will miss some true neighbors that share no words. Long empty reasons could still sneak through. Must not add a second unpaid model call while auto-run is filing.

Sketch: write the why once. Later screens read it.

3 Ask must say which kind of miss it is

Confidence 85% Complexity Medium
Description
Filing already has three answers: atom, task, noise. Ask has one empty list for two opposite worlds — “I have this, under other words” and “you never wrote this.” Give Ask three answers too: found, words do not match, really not here. Never return a blank list. Every answer says how it searched, how much of the body it saw, and whether the hit is thin. Claude may say “you have nothing on this” only when the answer is really-not-here. The miss can be a card: “12 cooking notes, none mention onions.”
Basis
direct: A note about Ross retention and a question about “how to stop viewers from clicking away” share no words, so Ask returns the same empty list as a true miss. We index about the first 200 characters of a body that is often ten times longer. “Thai place → onions” is world knowledge the vault does not contain.
external: A clean map with no warp marks is the one that lies.
reasoned: We already chose not to add meaning-search. Honesty does not need that. Extra hint fields still let a chat flatten the result into “nothing.” A required miss object does not.
Rationale
People judge the second brain in chat. A confident “you have nothing” is worse than a slow hit.
Downsides
Chat tools will ignore extra fields unless the miss is a required object, not a footnote. “Words do not match” can feel like hedging. Must not become an excuse to add meaning-search.

Sketch: filing already has three answers. Ask still has one empty.

4 Show today’s notes on yesterday’s graph, and say if capture landed

Confidence 74% Complexity Medium
Description
Keep the rule: do not file today, do not rewrite the daily, do not let the model title today’s bullets. Still show those bullets on Home as wet notes sitting next to two or three older atoms they would belong with. Tomorrow’s Process keeps or drops those ghost links. Also show a simple pulse: “last capture landed 2 hours ago” versus “nothing landed since yesterday.” No streak. No opening the inbox file.
Basis
direct: Day one is silent on purpose: the window starts today, today is skipped, first atoms appear tomorrow. People never open the inbox file. They have seen “4 captures need a fix” with no way to act.
external: Other daily-note apps treat today as the inbox you can already see.
reasoned: Not filing today is not the same as hiding today. A blank Home on the first day feels like the product is off. The only capture status a phone user can act on is “did it land?”
Rationale
Day one can prove the graph before any file is written. A lost capture stops looking like a rest day.
Downsides
Ghost links can look like finished atoms. The pulse can become a streak if the copy slips. Today must stay read-only — no files, no markers, no model titles.

Sketch: today is visible and still not filed.

5 Home has three looks: quiet, blocked, broken

Confidence 80% Complexity Medium
Description
One shared “is filing actually running?” answer, used by Home, auto-run, and Plus copy. Home then has three looks, never one idle: quiet (nothing to show, and that is fine), blocked (name the gate and the one thing to do), broken (no key, bad Plus address, login refused, or a stuck sync whose only exit today is reload). Settings is the repair sheet for blocked and broken, not a place you live. “Cannot reach Plus” and “Plus refused you” are different sentences. “Offline” is reserved for no network.
Basis
direct: A deleted key still produced “Atoms files each past day when Obsidian opens,” because the screen trusted local stamps instead of “do we have a way to file?” A 401 from a proxy reads as “you’re offline” and never reaches the recovery row. A moved phone can lose filing with no explanation. A bad Plus address stops auto-file with no why. A card that offers an action you cannot take is worse than silence.
external: Lighthouses use different flashes so “the lamp is out” and “no ships tonight” never look the same.
reasoned: Plus work shipped new checks without a Home look the phone can see. Paid filing dying while Ask still answers is the worst Plus failure.
Rationale
Filing that works is the product. This makes the truth visible on Home instead of buried in Settings.
Downsides
Three looks can become a status dashboard if every leftover bug gets its own card. Stay at three. Do not nag on a healthy rest day.

Sketch: quiet, blocked, and broken no longer share one empty screen.

6 Search title, tags, and link words first; then walk the links

Confidence 76% Complexity High
Description
Filing already paid for a title, tags, and link words. Search those as their own fields, in one shared finder used both when we file and when we Ask. On first sync, fill Ask’s extra phrases from those same fields. Call the model for more phrases only when that is not enough. If search still comes up empty, walk the strong links you already wrote — “this note named that note, for this why” — and label the result as a walk, not as “the vault understood you.” Do not invent new people or trip hubs. Do not add meaning-search yet.
Basis
direct: The retrieval note already says: the title, tags, and link words are extra search terms we already paid for. Pulling neighbors of the top hits into the shortlist is written down and untested. Filing search and Ask search are two different scorers. Empty is not the same as “not in the vault.”
external: Disease tracing follows named contacts, not a word count of the neighborhood.
reasoned: The miss we keep seeing is different words for the same thought. Searching a longer body does not fix a zero-word overlap. Two finders will pick two next experiments.
Rationale
One finder means the next search improvement helps filing and Ask together. The words we already wrote stop sitting unused next to the body.
Downsides
Unifying plugin search and Plus Ask is real work, not a rename. A link-walk can look like “it understood me” if we do not label it. Walking weak links rehearses the sticker-reason bug (needs idea 2).

Sketch: try the words you already paid for, then follow the links.

7 Old history is a map you pick from, not a sweep

Confidence 68% Complexity High
Description
Backfill is the only way to file the far past, and it is priced. Flip it. One run looks at old captures in memory and shows a map: which twenty new atoms would create the first real link, the first person cluster, or the first “I used to think.” You buy those. The rest stay unfiled on purpose. Yesterday still files on its own. A three-year-old stamp must not hide that map or quietly file the whole past for free.
Basis
direct: Backfill is the only road to history, and one tap must not spend a whole month’s allowance. A far-past start date can hide the offer, so the past runs through the quiet unpaid path.
external: A map you edit is you tending the brain. A meter you watch is not.
reasoned: A decade of dailies either dies at the confirm sheet or gets swept. Picking the twenty edges that change the drawing spends money on a brain, not on a pile.
Rationale
Old notes stop being “file everything or file nothing.” A ten-year vault can change the graph in one sitting without burning the month.
Downsides
Looking at a decade in memory is costly. A map of 200 “first edges” is another card you cannot act on. Picking twenty can feel like the product is withholding. Need a hard cap and a way to ignore the map.
