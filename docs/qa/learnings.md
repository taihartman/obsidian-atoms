# QA learnings

Project-owned trap list. `world-class-qa` reads this before every drive and appends after a pass that taught something the next pass would otherwise repeat.

Dated reports under `docs/qa/YYYY-MM-DD-*.md` are evidence. This file is memory. One row per trap. No credentials, tokens, or private account data.

| 2026-08-15 | Shared throwaway vault | **There is no lock on `test_vault/test vault`, and a peer session's `install-to-vault.sh` silently replaces your build mid-pass.** Verified: an install landed 0.8.0 at 09:19 and a probe confirmed it at 09:21; by 09:23 a peer worktree on another branch had overwritten `main.js` with its own 0.7.12. A drive that started in between would have screenshotted the *old* copy and reported it as a regression in the new one. The repo locks a shared *device* (`qa_device_lock.sh`) but nothing locks a shared *vault*. | Before **and after** every capture batch, assert build identity by grepping the installed `main.js` for a string this branch introduced — not by reading `manifest.json`, which named a plausible version in both builds. If the two checks disagree, throw the frames away. Check `git worktree list` for a peer on a related branch before assuming the vault is yours. |
| 2026-08-15 | Bundle grep | Non-ASCII in `main.js` is `\uXXXX`-escaped, so `grep -F "predictable — tap again"` returns 0 **even when that exact old copy is present**. A "the fix shipped" check written that way passes vacuously. | Grep the ASCII stem (`cost stays predictable`) and read the escape, or grep `\\u2014` directly. |

The app stays alive at 0% CPU, so it looks healthy. This takes down every concurrent session's QA, not just yours. | Do not reach for `obsidian://open` to mint a QA vault. Register a vault by opening it in the app once, by hand. If the CLI is already hanging, `pkill` the orphan clients and quit/relaunch Obsidian. |

It poisoned 14 of 16 frames before a reviewer looking at the images caught it. ## How to add a row

- The next pass would otherwise re-pay the same cost (wrong handle, screenshot race, forbidden data path, construction that cannot fail).
- Not a one-off product bug with its own test — those go to the report and, if durable, `docs/solutions/`.
- Keep the row to one line. Link a solutions doc or nav-map row when the how-to is longer.
