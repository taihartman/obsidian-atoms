# QA learnings

Project-owned trap list. `world-class-qa` reads this before every drive and appends after a pass that taught something the next pass would otherwise repeat.

Dated reports under `docs/qa/YYYY-MM-DD-*.md` are evidence. This file is memory. One row per trap. No credentials, tokens, or private account data.

| 2026-08-15 | Driving Obsidian by mouse | **Do not fall back to computer-use clicks when an eval will not reach the screen. The screenshot's coordinates do not map to the live display.** Chasing a Notice frame for #509, every `left_click` inside the visible Settings window was refused with "would land on the desktop shell", at coordinates the returned image plainly showed as inside that window. The screenshot filter hides non-allowlisted apps at the compositor and they return the instant it is taken, so the image is a composite the real screen never showed. Roughly thirty tool calls went to this after the *documented* CLI route (the Settings eval and Notices rows below) was skipped. | Read the four rows below before driving anything: `settingTab.containerEl` for the screen, two evals for opening Settings, a `MutationObserver` for a Notice. They are the supported path and they work. If a Notice frame still cannot be reached from the CLI, hand the click to a human and say so in the report — do not spend a session on the mouse. |
| 2026-08-15 | Shared throwaway vault | **There is no lock on `test_vault/test vault`, and a peer session's `install-to-vault.sh` silently replaces your build mid-pass.** Verified: an install landed 0.8.0 at 09:19 and a probe confirmed it at 09:21; by 09:23 a peer worktree on another branch had overwritten `main.js` with its own 0.7.12. A drive that started in between would have screenshotted the *old* copy and reported it as a regression in the new one. The repo locks a shared *device* (`qa_device_lock.sh`) but nothing locks a shared *vault*. | Before **and after** every capture batch, assert build identity by grepping the installed `main.js` for a string this branch introduced — not by reading `manifest.json`, which named a plausible version in both builds. If the two checks disagree, throw the frames away. Check `git worktree list` for a peer on a related branch before assuming the vault is yours. |
| 2026-08-15 | Bundle grep | Non-ASCII in `main.js` is `\uXXXX`-escaped, so `grep -F "predictable — tap again"` returns 0 **even when that exact old copy is present**. A "the fix shipped" check written that way passes vacuously. | Grep the ASCII stem (`cost stays predictable`) and read the escape, or grep `\\u2014` directly. |
| 2026-08-15 | `atoms:process-fixture-sample` | It is **not in any `install-to-vault.sh` build**. Its absence from the palette is the define, not a broken plugin. | For a credential-free fixture write, `npm run dev` and hand-copy `main.js`. | 2026-08-15 | `dev:screenshot` | The stale-frame window is exactly **one** frame deep: capture N returns capture N−1's state, observed directly (after a state change the first frame returned the previous frame's hash byte-for-byte). | 2026-08-15 | Notices | A Notice vanishes inside a single CLI round-trip, and async results land after two or more — so a plain `.notice` read after `command` gets the in-flight text or nothing. | Install a `MutationObserver` pushing `.notice` textContent into a `window` global before firing the command, then read the global. |
| 2026-08-15 | New QA vault | **A vault Obsidian has never opened starts in Restricted Mode, and the CLI hides it perfectly.** `eval` and `dev:screenshot` answer normally, `app.plugins.enabledPlugins` still lists `atoms`, and `community-plugins.json` looks right — but `app.plugins.plugins` is `{}` and every plugin command silently does nothing. | 2026-08-15 | `obsidian://open` | Opening a vault by URI that Obsidian has **never registered** did not open it and **wedged the CLI**: the vault stayed absent from `obsidian.json`, and every later `obsidian` invocation hung forever, stacking orphan clients. The app stays alive at 0% CPU, so it looks healthy. This takes down every concurrent session's QA, not just yours. | Do not reach for `obsidian://open` to mint a QA vault. | 2026-08-14 | Settings sheets | A sheet left open from an earlier step greys out the whole page, and a JS `.click()` still changes routes *underneath* its scrim, so a capture run keeps "succeeding" while every frame shows a modal over a dimmed screen. | 2026-08-14 | Phone viewport | `@electron/remote` is not a "try" — it works on 1.13.6. | `require("@electron/remote").getCurrentWindow().setContentSize(390, 844)` returns `[390,844]`, **then** `emulateMobile(true)` reaches `is-phone` in under 2s. Order matters: resize first, emulate second. |

## How to add a row

- The next pass would otherwise re-pay the same cost (wrong handle, screenshot race, forbidden data path, construction that cannot fail).
- Not a one-off product bug with its own test — those go to the report and, if durable, `docs/solutions/`.
- Keep the row to one line. Link a solutions doc or nav-map row when the how-to is longer.
