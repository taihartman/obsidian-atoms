Atoms settings — “Is it filing?”

The complaint is “it’s hard to know how to do things.” The screen’s row grammar is already fine — #304 fixed that. What’s missing is state: a signed-out install that cannot file anything looks almost exactly like one that files happily. This mock leads with the answer to “is Atoms working, and what’s the one next thing?”, then regroups the rest by the three questions the pipeline actually asks.

What this mock changes
  1. A status card is the first thing on the screen — one sentence about this install, and the single next step as the only primary action.
  2. The engine becomes one segmented row. Atoms Plus and Your API key (optional) are five headings apart today; nothing says pick one. Now it’s one fork, made once.
  3. Filing + Automatic filing (this device) merge. Two near-identical headings owning unrelated things is the clearest navigation bug on the screen.
  4. Ask collapses to one row when it’s unusable — signed out it currently spends a heading, two paragraphs, and two full-width buttons on a feature you can’t reach.
  5. Consent records gather under Privacy & data, quiet. Closes #364 C2 — records currently shout louder than the toggles that grant them.
  6. Diagnostics and internal vocabulary move out — Last auto-run day, drain → outbox → mirror, data.json, SecretStorage.

Capture on your phone

Three steps, once. Takes about a minute.

    Opens Capture Atom v2.2.0 in Shortcuts

  3. Try it
    Say or type a thought. It lands in today’s daily note.
Why this is a sheet, not a caption

Today this six-step procedure lives inside a row description: “After Add Shortcut: Shortcuts → Capture Atom → edit → Append to Bookmark → Atoms Inbox (not Ask Each Time) → Done. Open Obsidian with Atoms once first so that bookmark exists.”

A caption is where a user skims. A procedure with a mandatory ordering and a failure mode (“not Ask Each Time”) needs its own surface, one step visible at a time, with the outcome stated. The row that opens it carries only a status: Not set up or Capture Atom v2.2.0.

Row grammar is unchanged from #304 — toggle = preference, chevron = destination, accent button = action, muted right text = status. This restructure moves rows between groups and adds one card; it does not invent a fifth grammar.

Every money, egress, and vault-write gate stays on the main screen. What moves into Privacy & data is the passive record of a consent, never the grant itself — the toggle that grants stays beside the feature it turns on.
