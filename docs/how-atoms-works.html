Inbox holds the raw line

The Shortcut prepends an ISO stamp with its own offset. That stamp picks the day. Seconds keep two same-minute captures distinct. The plugin never rewrites this line.

Classify names the claim. It never authors the body.

The model gets the capture plus a vault context shortlist (titles, tags, vocabulary). It returns a structured verdict: title, tags from the active list, proposed tags (inert), reason-bearing links, people. Enrichment then repairs people, media, and boilerplate link reasons.

Runtime pipeline

One function owns each seam. Filing logic lives in pipeline/. The plugin shell only wires lifecycle, commands, and home.

inbox.drain → daily

Move stamped inbox lines onto their own day’s daily. Hold future and unparseable stamps. Never guess a date.

getPastDailyNotesWithUnmarkedCaptures

Scan past dailies only. Today stays quiet so a mid-day capture is still in progress.

parseCaptures

Find each bullet’s extent and detect the sentinel. Wikilinks inside the capture do not count as processed.

buildContext

One ContextProvider seam: vault titles, tags, vocabulary, then a BM25 shortlist. Swappable without rewriting classify.

classify

Anthropic structured output (BYOK) or the Plus classify path. Cache the stable system+context prefix. Retry 429/5xx. Invariant: atom requires a title; non-atom forbids one.

enrich/*

Post-classify repair: people hubs, media tags, existing-title entity links, idea rescue from task/noise, less boilerplate link reasons.

render → preview or write

Dry-run shows the same atom and marker strings. Write creates Atoms/title.md and appends the marker. Collision policy sanitizes the filename and may add an alias.

Every capture gets a marker

The sentinel is the processed state. Re-process never happens while it sits under the capture. Task is soft-retired: classify should emit atom or noise.

atom

Keepable memory

Creates a file. Title, tags, and links are model output. Body is the capture, word for word. Lists and media dumps are atoms, not tasks.

Frontmatter is machine

Source points back at the daily. Quality stamps tell Update notes which files are stale. Open-loop fields mark an intention, not unfinished homework.

Body is you

Whitespace tidy-up only. Hedges and half-formed sentences stay. The model never “improves” this paragraph.

Links carry a reason

Prose after the body, not a bare list. Revises and contradicts feed mind-change on home. Relates is a soft edge.

What you see in the vault

One mobile-first leaf. Preview reuses dry-run. Process reuses the write path. Auto-run stays silent.

Waiting card

When past captures sit unmarked, home offers Preview and Process. A live progress card shows N of M, a snippet, and a bar. Done summary, then the library.

Resurface stream

Mind-change first (an older claim you later revised), then on-this-day, then named connected, then quiet. Soft throttle hides a card you already opened. Never a review queue.

Automatic filing

Opt-in, device-local. Needs an egress consent. Files only from the day you enabled it, forward, never today. History is a priced Backfill offer, not an unattended sweep.

Update notes

User-started refresh of older atoms: new titles, tags, links. Body stays. Never auto. Mutually exclusive with Process, Backfill, and Auto-run.

People and orbits

Process may invite Add Sam?. You create the hub. No silent stubs. When several atoms hard-link an existing hub, home can show Also about.

Open loops

An intention note is first-class. It stays open until a redeeming child exists. Ordinary continues do not close it. Browse and Review commands, not a guilt shelf on home.

Ask is a one-way copy

Plus mirrors flat Atoms/*.md to the cloud so Claude and ChatGPT can search it. The vault remains the source of truth.

Vault → cloud only

Edits, deletes, and renames on this device push after a 2s debounce. Nothing ever writes an atom body back from the cloud. Full orphan cleanup is Sync now.

Device-local evidence

Hash map and stamps live in local storage, not synced data.json. A device deletes remotely only paths it has hashed. API keys also stay on-device (SecretStorage).

Hard stops

Violating any of these is a bug, not a product tweak.

  • Body is sacred. Model output is title, tags, and links only.
  • No folder intelligence. Atoms stay flat. System files live in Atoms System/.
  • Today is excluded unless you explicitly force Preview or Process today.
  • Nothing is destroyed. Runs are idempotent. A bad classify still leaves the capture.
  • Proposed tags stay inert until you approve them into the vocabulary.
  • No task-app gravity. No due dates, streaks, or “you should process.”
