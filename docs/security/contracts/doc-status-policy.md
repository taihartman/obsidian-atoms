# Documentation status policy

Canonical security documents declare `status`, `owner`, `last_verified`, `canonical_for`, `supersedes`, and `superseded_by`. Allowed statuses are `canonical`, `draft`, `historical`, `needs-update`, and `superseded`. Canonical documents require a real review date; superseded documents name their replacement. Live enforcement and tests outrank stale prose.
