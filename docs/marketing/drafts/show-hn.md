**First comment (post immediately, sets the frame):**

I capture thoughts into Obsidian daily notes, fast and messy, and for years none of it came back. Atoms is a plugin that files those past captures into small linked notes.

The design constraint that shaped everything: the model never writes the note body. It writes a title, tags, and links with stated reasons. The body is your capture, word for word, hedges and all. A confident paraphrase of a half-formed thought misrepresents what you actually knew, and a second brain built from paraphrases rots quietly. So we do not paraphrase.

Everything is plain markdown files in one flat folder in your own vault. No proprietary database. Uninstall and nothing changes. The plugin is MIT.

Costs, plainly: filing calls a model, so you bring your own Anthropic key (Anthropic bills you) or pay for a hosted tier if you never want to hold a key. Resurfacing and browsing are free with no key. What each run sends is one short page: [what-leaves-your-machine URL]. There is also a documented self-host path for the cloud mirror piece.

Things it refuses to do: process today's note, move files, pick folders, rewrite anything, or become a task manager.

Happy to talk about the tension of using a model at all in a tool whose whole point is trusting your own words.
